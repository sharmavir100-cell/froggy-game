# 🐸 Froggy Game - Jump Into the Fun!

A colorful, interactive browser-based arcade game with simple gameplay and mobile support!

## 🎮 How to Play

- **Jump** over the incoming rock using the **JUMP button**
- Reach the lily pads to gain points
- Avoid hitting the rock!
- Test your reflexes and beat your high score

## ✨ Features

- 🎨 Colorful, retro arcade-style graphics
- 📱 Fully responsive - plays on desktop, tablet, and mobile
- 📲 Progressive Web App (PWA) - install as an app!
- 🔋 Offline support with service worker
- ⚡ Fast and lightweight (no frameworks needed)
- 🔄 Score tracking during gameplay

## 🚀 Play Online

Play directly on GitHub Pages: **[Froggy Game](https://sharmavir100-cell.github.io/froggy-game/)**

## 📥 Install as an App

1. Visit the game in your browser
2. Click the **Install** button (or the menu option to "Add to Home Screen" on mobile)
3. Launch Froggy Game like any other app!

## 💻 Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Service Worker (PWA)
